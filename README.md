# 🌌 Галактика признаний • Для Амины ❤️

Персональный интерактивный веб-сайт-подарок для Амины.

## ✨ Ключевые возможности

1. **💌 Шаг 1: 3D-Конверт и Сургучная печать**
   - Конверт с рукописным именем «Амина».
   - Тактильная сургучная печать с анимацией раскалывания на осколки.
   - Реалистичный звук хруста (Web Audio API) и тактильная вибрация (Haptic feedback).
   - Анимация распаковки конверта.

2. **📜 Шаг 2: Живое письмо**
   - Построчное проявление трогательного признания абзац за абзацем.
   - Искренний текст, написанный живым каллиграфическим почерком.
   - Автоматический запуск романтической музыки (*Arctic Monkeys — I Wanna Be Yours*).

3. **📸 Шаг 3: Полароид-карточка**
   - Эстетичное фото Амины в стиле Polaroid с памятной подписью.

4. **✨ Шаг 4: 3D-Галактика признаний (Главная фишка)**
   - Интерактивная 3D спиральная галактика из **9 494 признаний «Я тебя люблю»** на более чем 75 языках мира (Русский, English, Français, Español, 日本語, 한국어, العربية, Türkçe, Қазақша и др.).
   - Свободное вращение галактики пальцем на смартфоне или мышью на компьютере.
   - При нажатии: тысячи светящихся фраз плавно собираются в **портрет Амины**.
   - Интерактивный зум: можно приблизить любую часть лица и прочитать микро-текст признаний на разных языках, из которых сотканы её глаза, улыбка и черты лица.
   - Динамический счётчик вложенных признаний в реальном времени.

5. **✍️ Шаг 5: Финал и сохранение**
   - Рукописная золотая роспись «Амина» со звёздными искрами.
   - Кнопка **«📸 Сохранить себе»** — генерирует и скачивает портрет сверхвысокого разрешения прямо в галерею телефона.
   - Кнопка **«🔗 Поделиться»** — копирует персональную ссылку или открывает системное меню "Поделиться".
   - Плавающий виниловый плеер с песней *Arctic Monkeys — I Wanna Be Yours*.

## 🚀 Как запустить на GitHub Pages (Бесплатный хостинг по одной ссылке)

1. Перейдите в настройки репозитория на GitHub: **Settings** -> **Pages**.
2. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `(root)`
3. Нажмите **Save**.
4. Через 1-2 минуты сайт станет доступен по ссылке:
   `https://dibayo07.github.io/amina/`
